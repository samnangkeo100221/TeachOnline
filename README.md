# 📚 TeachOnline - ប្រព័ន្ធបង្រៀន និងប្រឡងអនឡាញ

កម្មវិធីបង្រៀន និងប្រឡងអនឡាញទំនើប រៀបចំ និងគ្រប់គ្រងដោយលោកគ្រូ **កែវ សំណាង** ផ្អែកលើគំរូដើម `code gs.txt` និង `index html.txt` ជាមួយការកែលម្អយ៉ាងទូលំទូលាយ មានផ្ទាំងគ្រប់គ្រងសម្រាប់គ្រូ ផ្ទាំងសម្រាប់សិស្ស ភ្ជាប់ជាមួយ **Supabase Database**, **Google Sheet**, និង **Telegram Bot**។

## 🌟 លក្ខណៈពិសេសសំខាន់ៗ (Features)

### ១. ផ្ទាំងគ្រូ និងផ្ទាំងសិស្សផ្សេងគ្នា (Separate Teacher & Student Portals)
- **ផ្ទាំងសិស្ស (Student Portal):** សិស្សអាចចូលរៀន មើលវីដេអូ អានមេរៀន និងប្រឡងបាន ដោយចូលតាមរយៈឈ្មោះ និងលេខសម្ងាត់សិស្ស។ សិស្សមិនអាចបើកផ្ទាំងគ្រូបានឡើយ។
- **ផ្ទាំងគ្រូ (Teacher Admin Panel):** គ្រូមានលេខកូដសម្ងាត់ការពារ (**Teacher PIN: `123456`**) ដែលគ្រូអាចបើកមើលទាំងផ្ទាំងសិស្ស និងផ្ទាំងគ្រូបានគ្រប់ពេលវេលា ដោយគ្រាន់តែចុចប៊ូតុងផ្លាស់ប្តូរនៅលើ Menu ខាងលើ។

### ២. ការមើល និងកែសម្រួលវីដេអូ (Universal Video Player)
- គាំទ្រការចាក់វីដេអូពីគ្រប់បណ្តាញសង្គម៖
  - **YouTube ធម្មតា** (`youtube.com/watch?v=...`, `youtu.be/...`)
  - **YouTube Shorts** (`youtube.com/shorts/...`)
  - **TikTok Videos** (`tiktok.com/@.../video/...`)
  - **Facebook Videos & Reels** (`facebook.com/.../videos/...`, `fb.watch/...`)
  - **វីដេអូផ្ទាល់** (`.mp4`, `.webm`)
- គ្រូអាចចូលទៅកែប្រែ ឬបន្ថែម Link វីដេអូពេលក្រោយបានគ្រប់ពេលវេលាក្នុងផ្ទាំង Admin។

### ៣. ការរចនាមេរៀនមានរបៀប និងរចនាបថស្រស់ស្អាត (Rich Lesson Viewer)
- បង្ហាញជាផ្នែកៗច្បាស់លាស់៖
  - 🎯 **វត្ថុបំណងមេរៀន (Objectives)**
  - 📖 **ខ្លឹមសារមេរៀន / ទ្រឹស្តី (Content)** (គាំទ្រអក្សរដិត ពណ៌ និង Markdown)
  - 📐 **សង្ខេបរូបមន្ត (Formula Summary)** (គាំទ្ររូបមន្តគណិតវិទ្យា LaTeX / MathJax)
  - 💡 **ឧទាហរណ៍ និងដំណោះស្រាយ (Examples)**
  - 📌 **ចំណាំសំខាន់ៗ (Notes)**
  - ⚠️ **កំហុសឧស្សាហ៍ជួប និងការកែតម្រូវ (Common Errors)**
- គ្រូអាចចូលទៅកែសម្រួលខ្លឹមសារមេរៀនបានគ្រប់ពេល។

### ៤. ប្រព័ន្ធប្រឡងពេញលេញ (Interactive Exam Engine)
គាំទ្រគ្រប់ប្រភេទសំណួរដូចក្នុង `index html.txt`៖
1. **MCQ / MCQ_TEXT:** ជ្រើសរើសចម្លើយត្រឹមត្រូវជាអក្សរ
2. **MCQ_IMAGE:** មើលរូបភាព រួចជ្រើសរើសចម្លើយ
3. **MCQ_AUDIO:** ស្តាប់សំឡេង រួចជ្រើសរើសចម្លើយ
4. **TRUE / FALSE:** ជ្រើសរើស ត្រូវ (TRUE) ឬ ខុស (FALSE)
5. **FILL IN THE BLANKS:** បំពេញចន្លោះប្រហោងដោយប្រើ `{{input1}}`, `{{input2}}`
6. **SHORT ANSWER:** សរសេរចម្លើយខ្លីដោយខ្លួនឯង (មានការផ្ទៀងផ្ទាត់ដោយ Gemini AI)
7. **MATCHING:** ផ្គូផ្គងជម្រើសខាងឆ្វេង ទៅខាងស្តាំ ដោយមានខ្សែភ្ជាប់ (Visual Connecting Lines)
8. **DRAG & DROP:** ចុចលើពាក្យដើម្បីរៀបលំដាប់ពាក្យក្នុងប្រយោគ
9. **DRAG ANSWER:** ចុចជ្រើសរើសពាក្យដែលត្រូវដាក់ចូលប្រអប់
10. **LISTENING & SPEECH (TTS):** បញ្ចេញសំឡេងអានជាភាសាអង់គ្លេស ខ្មែរ ចិន និងមានកន្លែងស្តាប់រួចសរសេរ
11. **READING COMPREHENSION:** អានអត្ថបទ រួចឆ្លើយសំណួរ

### ៥. ការផ្តល់ពិន្ទុ និងកត់ត្រាលទ្ធផល (Scoring & Cloud Storage)
- គណនាពិន្ទុ និងភាគរយដោយស្វ័យប្រវត្តិតាមសំណួរនីមួយៗ (រួមទាំងពិន្ទុសម្រាប់សំណួរផ្គូផ្គង និងបំពេញចន្លោះ)
- បង្ហាញផ្ទាំងលទ្ធផលលម្អិតធៀបរវាងចម្លើយសិស្ស និងចម្លើយត្រឹមត្រូវ
- **រក្សាទុកទិន្នន័យទៅកាន់ Supabase Database** ដោយស្វ័យប្រវត្តិ
- **បញ្ជូនបន្ត (Forward) ទៅកាន់ Google Sheet** តាមរយៈ Google Apps Script Web App
- **ផ្ញើសារជូនដំណឹងទៅកាន់ Telegram Bot ភ្លាមៗ** ពេលសិស្សប្រឡងរួច

## 🛠️ ការរៀបចំដំឡើង (Setup Guide)

### ១. ការរៀបចំ Supabase Database
1. បង្កើតគម្រោងថ្មីនៅលើ [Supabase](https://supabase.com)
2. ចូលទៅកាន់ម៉ឺនុយ **SQL Editor** ក្នុងផ្ទាំង Supabase
3. បើកឯកសារ `supabase/schema.sql` រួចចម្លង (Copy) កូដ SQL ទាំងមូលមកបិទភ្ជាប់ (Paste) ហើយចុច **Run**
4. ចូលទៅកាន់ **Project Settings -> API** រួចចម្លងយក៖
   - `Project URL`
   - `anon public key`
5. បើកកម្មវិធី TeachOnline ចូលទៅកាន់ **ផ្ទាំងគ្រូ (Teacher Panel) -> ការកំណត់ & Cloud** រួចបិទភ្ជាប់ Supabase URL និង Anon Key ហើយចុច **រក្សាទុក**។

### ២. ការរៀបចំ Google Sheet & Telegram
1. បង្កើត Google Sheet ថ្មីមួយ
2. ចូលទៅកាន់ **Extensions -> Apps Script**
3. ចម្លងកូដពីឯកសារ `google-apps-script/Code.gs` មកដាក់ក្នុង Apps Script
4. ចុច **Deploy -> New deployment**
   - ជ្រើសរើសប្រភេទ៖ **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. ចម្លង **Web App URL** ដែលទទួលបាន មកដាក់ក្នុងទំព័រ **ការកំណត់ & Cloud** របស់កម្មវិធី TeachOnline។
